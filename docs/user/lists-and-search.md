# Lists and search

## The list of records

Choose a table in the sidebar to see its records as a list. The line under the table's name says how many records there are and how they are sorted, for example "3 records, sorted by Name, A to Z". Choose a record's title to open it.

If the table has no records yet, the list says so; choose **Add item** to add the first one. If the table has no fields yet, an Admin needs to add some first.

## Finding records in a table

Type part of a name, or any other text, in the "Find in Items" box above the list, and choose **Apply**. The list then shows only the records that hold that text, and the line under the table's name says how many match out of how many in all.

- Find looks at text, long text, choice, web address, email, and phone fields, and at the titles of linked records. It does not look at numbers or dates; use a filter for dates.
- Capital and small letters count as the same for the letters A to Z. For other letters, such as accented ones, type them as they are written in the record.
- If nothing matches, the page says so. Choose **Show every record** to see the whole list again.

## Sorting

Choose an order in the "Sort by" menu and choose **Apply**. Most fields can be sorted both ways, in words that fit the field: A to Z for text, lowest first for numbers, oldest first for dates, list order for choices, and so on. The menu also has "Newest added first", "Oldest added first", and "Recently changed first".

Sorting and finding work together: choose both, then **Apply** once.

## Filtering

A filter shows only the records that match one condition, such as "Room is Kitchen". Filters work on choice, checkbox, link, date, and date-and-time fields.

1. Choose **Filter** above the list.
2. On **Filter Items**, choose the field and then **Next**.
3. Choose the condition. Depending on the field, it can be:
   - a choice field: is a particular choice, or is empty;
   - a checkbox: is ticked, or is not ticked;
   - a link field: links to a particular record, or has no link (only the first 500 records are listed to choose from);
   - a date or date-and-time field: is in a range, From one date To another, or is empty. Leave one end empty for an open range, such as "on or after 1 January".
4. Choose **Show matching records**.

The list then says which condition it is showing, for example "Showing only records where Room is Kitchen". Choose **Remove the filter** to see every record again. **Choose another field** on the filter page starts again with a different field.

A filter, a find, and a sort can all be used at the same time. If a field used by a filter is changed or deleted, TiffinDB shows every record and says the filter could not be used.

To keep a search with more than one condition, make a collection instead (see [Collections](collections.md)).

## Pages of records

A list shows 50 records at a time. Under the list, TiffinDB says which records are shown, for example "Showing 1 to 50 of 120", and **Previous** and **Next** move between pages.

## Searching all tables

Inside a project, the search box in the top bar looks through every table of the project at once. Type a word and press Enter.

**Search results** shows the matching records grouped by table, with how many matched in each. When the text was found in a field other than the title, the field and the text around it are shown under the title. Up to 10 records are shown for each table; when there are more, **Show all 12 in Items** (with your own number and table) opens that table's list with the same text found.

If nothing is found, the page says so. Check the spelling, or try a shorter word.

The search looks at the same fields as finding in a table: text, long text, choice, web address, email, and phone fields, and the titles of linked records. Records in the trash are not searched.
