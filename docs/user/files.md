# Files

A file field keeps files with a record: photos, receipts, manuals. Files are added one at a time, and a record can hold up to 100 files in each file field.

Files can be added only after the record has been saved once. Until then, the field says "You can add files once this record is saved."

## Which files show as pictures

Pictures in PNG, JPEG, GIF, or WebP are shown on the record screen. Every other kind of file, including PDF, is kept for download: the record shows its name, its kind, and its size.

An Admin can set a file field to accept only pictures. Its button then says **Add an image** instead of **Add a file**, and any other kind of file is refused.

## Adding a file

1. Open the record. If you have changed any of its fields, choose **Save** first: the file buttons leave the page.
2. In the file field, choose **Add a file** (or **Add an image**).
3. On the page that opens, choose the file on your device. The page says how large a file may be; this depends on how your TiffinDB is set up.
4. Choose **Add the file**.

TiffinDB goes back to the record and says the file has been added. **Cancel** goes back without adding anything.

If the file is too large, empty, or does not arrive completely, the page says so and nothing is added. Try again, or choose a smaller file.

## Opening a file

Choose **Open** beside a file. The page shows:

- the picture itself, for a picture;
- for any other file, a note that TiffinDB does not show this kind of file;
- what kind of file it is, its size, and when and by whom it was added;
- **Download**, which saves the file to your device;
- **Replace** and **Remove** (see below), and **Back to Stand mixer**, with your own record's title, to return to the record.

## Replacing a file

Choose **Replace** beside the file, either on the record or on the file's own page. Choose the new file and then **Replace the file**. The new file takes the place of the old one in the same field. The old file is deleted from TiffinDB when the new file is saved.

## Removing a file

Choose **Remove** beside the file. The page asks **Remove manual.pdf?**, with your own file's name. Choose **Remove the file** to remove it from the record and delete it from TiffinDB.

Removing a file cannot be undone. A removed file does not go to the trash.

## Files and the trash

When a record is moved to the trash, its files stay with it, and they come back when the record is restored. When an Admin empties the trash, the files that only those records held are deleted for good (see [The trash](trash.md)).
